# Premium target source art

These are the twelve untouched RGBA PNG source files supplied for the premium target, geometry-retirement,
and destruction passes.
They are not loaded by the game at runtime. Run `npm run assets:premium` to alpha-crop and resize
the corresponding transparent WebP files in `public/assets/premium/`.

Common Hunter Drone, Antimatter Reactor Pod, and Shielded Cargo Drone bodies use more aggressive
runtime dimensions than the large yacht, datacenter, and carrier prestige targets.

Do not replace these files with the retired sprite-atlas or checkerboard-background experiments.
